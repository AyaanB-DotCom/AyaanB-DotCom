### ~/research

**01 — android tv box**

Investigating a low-cost Android TV box associated with malicious software. Accessed U-Boot over UART, extracted the Android system partition from eMMC, and performed static malware analysis.

`firmware` `uart` `u-boot` `emmc` `malware analysis`

[featured in hackaday ↗](https://hackaday.com/2026/08/28/this-week-in-security-android-malware-voip-hijack-signal-contact-discovery-and-teampcp-arrests/)

**02 — white buffalo roam**

An investigation into unexpected audio data recovered from a generic MP3 player. Exploring filesystem artifacts, storage behavior, and the origins of a hidden recording.

`digital forensics` `file carving` `binary analysis`

[read the investigation ↗](https://github.com/AyaanB-DotCom/White-Buffalo-Roam)

**03 — cowrie**

Deploying and studying an SSH honeypot to observe real-world attack patterns, credential attempts, and suspicious command execution.

`honeypots` `threat intelligence` `linux` `log analysis`

**04 — llm security**

Research into security vulnerabilities affecting large language model applications, including prompt injection and risks described in the OWASP Top 10 for LLM Applications.

`ai security` `owasp` `prompt injection`
